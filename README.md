# Tally

A desktop expense ledger for one person: type transactions in or import the
CSV your bank exports, sort them into categories with simple payee rules,
and see each month against a budget. Everything stays in one local file; no
bank connection, no account, no network. Windows x64, macOS on Apple silicon
and Linux x64. See `PRODUCT.md` for the brief and `CHANGELOG.md` for what is
in each version.

Generated by Keel from the `electron-web` template. Contributors start with
`AGENTS.md`.

## Commands

```bash
npm install
npm run typecheck         # tsc over the renderer, electron/ and the suites
npm run test:unit         # core: money, dates, CSV, import, rules, summary, find, undo
npm run test:contract     # the labelled mock and the file-backed backend answer alike
npm run test:integration  # the ledger file in temp directories, crash and kill tests
npm run test:ui           # Playwright, chromium, against the labelled mock (TALLY_UI_PORT to move off 1420)
npm run build             # main, preload and renderer into out/ for the real-shell suite
npm run test:e2e          # Playwright's Electron launcher against the built app
npm run package           # unsigned installers into release/
```
