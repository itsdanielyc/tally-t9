## Downloads

| System | File | How to install |
|---|---|---|
| Windows 10 and 11, x64 | `tally-0.1.0-x64-setup.exe` | Run it; it installs for your user only, no administrator rights. |
| macOS on Apple silicon | `tally-0.1.0-arm64.dmg` | Open it and drag tally into Applications. |
| Linux x64 (Debian, Ubuntu) | `tally-0.1.0-amd64.deb` | `sudo apt install ./tally-0.1.0-amd64.deb` |
| Linux x64 (other) | `tally-0.1.0-x86_64.AppImage` | `chmod +x` it and run it. |

`SHA256SUMS-<runner>.txt` lists the checksum of every file built on that
runner.

## Signing: these bundles are not signed

Tally 0.1.0 is unsigned on every system (decided in ADR 001). Your system
will warn you the first time:

- **Windows**: Microsoft Defender SmartScreen shows "Windows protected your
  PC". Choose "More info", then "Run anyway". Signing would need a
  code-signing certificate (OV or EV, a yearly cost) or Azure Trusted
  Signing (a monthly subscription); reputation then builds over time.
- **macOS**: the first open is blocked ("Apple could not verify 'tally' is
  free of malware"). Open System Settings, Privacy & Security, and choose
  "Open Anyway" for tally, or run `xattr -cr /Applications/tally.app`.
  Signing and notarization would need a paid Apple Developer account (a
  yearly fee).
- **Linux**: packages are not signed; compare the file with the published
  SHA-256 checksum.

## Your data

Everything stays in one file, `ledger.json`, in Tally's data folder
(`%APPDATA%\tally` on Windows, `~/Library/Application Support/tally` on
macOS, `~/.config/tally` on Linux); Settings shows the exact path. A backup
of the previous save sits beside it as `ledger.json.bak`. Tally makes no
network connections.

## Evidence

Proven before the tag, per `VERIFICATION.md`:

- Every test level from type checks to the real app (unit, contract,
  integration with crash and kill tests, the browser suite with
  accessibility, layout and per-OS pixel checks, and the real-shell
  journeys) green on Windows x64, macOS arm64 and Linux x64 runners
  ([run 44373011782](https://github.com/itsdanielyc/tally-t9/actions/runs/44373011782)).
- The installer round trips (install, launch, uninstall for NSIS, dmg, deb
  and AppImage) on the tagged commit: the release workflow refuses the tag
  unless the `installers` workflow passed on that exact commit, and its own
  build jobs run the round trips again.
